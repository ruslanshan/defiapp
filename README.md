# Yield Ladder — Telegram Mini App

Репозиторий `defiapp`, бот [@yieldladder_bot](https://t.me/yieldladder_bot).

Приложение для выбора пула: куда поставить монету из топ-30 в пару, куда положить стейблкоины и где за депозит платят токенами проекта. Для каждого пула считаются те же показатели, что в таблице, — на ваш капитал. Подсвечены четыре главных: **твоя доля в пуле, твой доход в сутки, доход в месяц, APR**. Риск оценивается по тирам T1–T3.

## Вкладки

- **Пары** — DEX-пулы монет топ-30 по капитализации (со стейблом, с ETH или BTC, альт-альт) и перп-LP вроде GMX. Вид «Таблица» повторяет колонки вашей Google-таблицы: сеть, пул, протокол, уровень комиссии, TVL, объём за 30 дней, объём за день, объём/TVL, комиссии пула в сутки и четыре личных показателя.
- **Стейблы** — лендинг, сбережения (sUSDS и подобные), стейбл-LP и стратегии.
- **Награды** — пулы и протоколы, где за депозит дополнительно платят токенами проекта: какие токены, сколько процентов годовых и сколько это долларов в месяц на ваш капитал.
- **Методика** — формулы, тиры риска с обоснованием по каждому протоколу, списки сетей и монет.

Наверху каждой вкладки — «лестница риска»: лучший пул на уровнях T1, T2 и T3 для вашего капитала.

## Формулы (как в таблице)

```
Объём 1 день        = объём за 30 дней / 30
Объём / TVL         = объём 1 день / TVL
Комиссии в сутки    = объём 1 день × уровень комиссии
Твоя доля в пуле    = капитал / (TVL + капитал)
Твой доход в сутки  = комиссии в сутки × доля
Доход в месяц       = доход в сутки × 30
APR                 = доход в сутки × 365 / капитал
```

Отличие от таблицы одно: в таблице доля = капитал / TVL. Но депозит сам увеличивает пул, поэтому в маленьких пулах таблица завышает доход. Пример: в пуле с TVL $10 тыс таблица даёт долю 59% вместо 37% и APR 24% вместо 15%. Для лендинга и хранилищ без комиссий доход в сутки = капитал × APY / 365.

## Как устроено

```
collector/          сборщик данных (Python) → webapp/data.json
  collect.py        CoinGecko, GeckoTerminal, DefiLlama, Hyperliquid
  scoring.py        классификация токенов и тиры
  config.json       сети, лимиты, сколько пулов дополнять объёмом за 30 дней
webapp/             статический сайт = Mini App
  index.html, core.js
  tiers.js          классификация риска — правится руками
  data.json         создаётся сборщиком
bot/bot.py          бот: кнопка приложения и сводки /pairs, /stables, /rewards, /capital
.github/workflows/pages.yml   сборка каждые 2 часа и публикация на GitHub Pages
```

Источники данных:

- **CoinGecko** — топ-30 монет по капитализации без стейблкоинов и обёрток.
- **GeckoTerminal** — DEX-пулы этих монет в 10 сетях, включая Robinhood Chain: уровень комиссии, TVL, объём за 24 часа и дневные свечи за 30 дней.
- **DefiLlama Yields** — лендинги, сбережения, хранилища, перп-LP и награды токенами.
- **DefiLlama Coins** — символы токенов наград.
- **Hyperliquid API** — хранилище HLP.

Объём за 30 дней — отдельный запрос на каждый пул, а бесплатный лимит GeckoTerminal — 30 запросов в минуту. Поэтому он собирается для 200 самых активных и доходных пулов (`ohlcv_pools` в config.json). У остальных расчёт идёт по объёму за 24 часа и помечен «24ч». Полная сборка занимает около 10 минут.

## Запуск

### 1. Сайт и данные на GitHub Pages (бесплатно, без сервера)

1. Создайте на GitHub **публичный** репозиторий `defiapp` и загрузите в него содержимое архива (папку `.github` тоже — без неё не будет автообновления). В публичных репозиториях минуты Actions не ограничены.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Actions → «Обновить данные и опубликовать» → Run workflow. Через ~10 минут сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/defiapp/`, дальше данные обновляются каждые 2 часа.
4. **Рекомендуется:** бесплатный ключ CoinGecko Demo в Settings → Secrets and variables → Actions под именем `COINGECKO_API_KEY`. Серверы GitHub общие, и бесплатный лимит GeckoTerminal на них часто выбран чужими проектами. С ключом сборщик при отказе берёт те же данные через CoinGecko Demo API, лимит которого считается по ключу. Без ключа сайт тоже работает, но объём за 30 дней будет дособираться по частям в течение нескольких запусков.

Объём за 30 дней кэшируется: сборщик берёт его из прошлой выгрузки на сайте и запрашивает у каждого пула раз в сутки. Расход по ключу — около 200–300 запросов в день при лимите Demo-ключа 10 000 в месяц; дневной потолок задаётся в `config.json` (`coingecko_daily_calls`).

GitHub отключает расписание, если в репозитории 60 дней не было коммитов. Если данные перестали обновляться, включите workflow заново во вкладке Actions.

### 2. Бот

1. Создайте бота в [@BotFather](https://t.me/BotFather) командой `/newbot` и заполните его профиль текстами из раздела «Оформление бота» ниже.
2. Привяжите приложение: в @BotFather → `/mybots` → бот → Bot Settings → Configure Mini App (или Menu Button) → адрес из шага 1.3. Бот из следующего пункта делает это сам.
3. Для команд /pairs, /stables, /rewards и /capital запустите бота на любом сервере (Python 3.10+):

   ```bash
   pip install -r requirements.txt
   export BOT_TOKEN="123:ABC..."
   export WEBAPP_URL="https://ВАШ-ЛОГИН.github.io/defiapp/"
   python bot/bot.py
   ```

### Альтернатива: всё на своём сервере

Вместо GitHub Actions можно запускать сборщик по cron (`17 */2 * * * python collector/collect.py`), а папку `webapp/` раздавать любым веб-сервером с HTTPS. Тогда боту можно указать `DATA_PATH=/путь/к/webapp/data.json`.

### Проверить локально

```bash
pip install -r collector/requirements.txt
python collector/collect.py --ohlcv 20      # быстрая сборка: объём за 30 дней только для 20 пулов
cd webapp && python -m http.server 8000     # откройте http://localhost:8000
```

Двойной клик по index.html не подойдёт: браузер не даёт странице с диска прочитать data.json.

## Настройка

- **Тиры, стейблкоины, сети, токенизированные акции** — `webapp/tiers.js` (JSON между маркерами). Протокол, которого нет в списке, автоматически получает T3. Если DEX или протокол переименуют, допишите новое название в `aliases`.
- **Монеты вне топ-30** — `assets.extra_assets`. Сейчас там токенизированные акции на Robinhood Chain: NVDA, SPCX, SPY, AAPL, TSLA, COIN. Каждая монета учитывается только в указанных сетях, чтобы одноимённые подделки не попадали в выборку.
- **Сети и лимиты сборщика** — `collector/config.json`. Если GeckoTerminal поменяет id сети, сборщик найдёт её по названию (поле `match`).
- **Защита от подделок** — токен из пула сверяется с CoinGecko: одноимённый, но другой токен отбрасывается, а токен без листинга получает T3 и предупреждение.

## Ограничения

- APR не учитывает непостоянные потери. Для Uniswap V3/V4 он показывает средний доход пула на вашу долю. При узком диапазоне можно заработать больше, а при выходе цены за диапазон — ноль.
- Награды токенами пересчитаны в доллары по текущей цене токена.
- Классификация риска экспертная, по состоянию на 7 октября 2026 года.

Это аналитический инструмент, а не инвестиционная рекомендация.
